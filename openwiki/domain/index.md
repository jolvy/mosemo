# 파일

- [활동 분석](activity-analytics.md) - 활동 분석 C1~C7의 범위, ADR 0016을 바탕으로 구현한 analytics BC(일간 통계·세션 분석 조회 API, 다시 계산 표시 handler, 일간 통계 배치와 정의 재처리), 운영 절차, 근거 문서와 시험 자원을 정리한다.
- [제품 기능과 도메인 용어](product-overview.md) - PRD·요구사항·용어집으로 본 Mosemo 서버의 기능 범위(Device 등록, 활동 관찰과 배치 전달, 관찰 타임라인, 집중 세션, 라벨링, 설계 중인 활동 분석)와 핵심 용어, 각 기능을 맡는 BC와 공개 API를 정리한다.

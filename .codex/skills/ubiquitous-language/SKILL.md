# 유비쿼터스 언어

## 사용 시점과 읽을 자료
용어집만 작성·검토·갱신하는 요청으로 독립적으로 실행하거나, 요구사항 탐색·명세·모델링·구현 중 새로운 업무 개념·정의의 공백·의미 충돌이 생기면 사용한다. 이번 변경의 동작이나 인수 조건에 영향을 주는 용어만 다루며, 모든 작업의 필수 선행 단계로 삼지 않는다.

`AGENTS.md`와 사용자 설명을 확인하고 기존 용어집·관련 요구사항·PRD·ADR은 존재하는 경우 참조한다. 필요한 범위의 코드·테스트·외부 계약을 확인한다. 다른 Skill 실행이나 문서 생성을 요구하지 않으며, 용어집이 없어도 시작한다. 코드와 필드명은 현행 표현의 증거이며 업무 의미의 최종 결정은 아니다.

작성·갱신 대상은 `docs/ubiquitous-language.md`다. `AGENTS.md`는 작업 규칙을 확인할 자료다.

## 절차
1. 누가 어떤 업무 질문이나 결정에 사용하는 말인지 맥락을 정한다. 기존 정의와 사용자 결정을 재사용하고, 같은 단어의 다른 뜻이나 다른 단어의 같은 뜻을 확인한다. 맥락이 다른 개념을 하나의 정의로 억지로 합치지 않는다.
2. 추가·변경이 필요한 용어의 의미와 경계를 확인한다. 대표 단위, 동일성, 포함·제외 사례, 관계의 역할, 사실·해석·확정 판단의 구분 중 용어를 구별하는 데 필요한 것만 검토한다. 객체의 책임·협력과 저장 구조는 engineering-planning에서 다룬다. 용어를 정의했다는 이유로 Entity·테이블·이벤트를 만들지 않는다.
3. 대표 용어와 짧은 정의, 필요한 예시·반례, 기존 의미와의 차이를 제시한다. 허용 동의어와 혼동을 만드는 표현을 구분한다. 새로운 정책이나 기존 정의를 바꿔야 한다면 영향받는 요구사항·PRD·계약·모델을 알리고 추천안·이유·대안의 비용을 제시하여 필요한 사용자 결정을 받는다.
4. 합의된 의미를 용어집에 반영한다. 이미 사용자가 결정했거나 요구사항·PRD 승인에 명시적으로 포함된 의미는 다시 승인받지 않는다. 의미가 같은 표현 정리와 합의된 내용의 기록에는 별도 승인을 요구하지 않는다. 읽기 전용 요청에서는 초안만 제시한다.
5. 정상·경계 사례를 정의로 설명할 수 있는지, 관련 요구사항·PRD와 일치하는지 확인한다. 변경한 용어와 근거, 검증 범위, 남은 충돌을 보고한다. 관련 요구사항·PRD가 있으면 결정 근거를 연결하고, 없으면 사용자와의 합의 근거를 대화에서 보고한다. 추적을 위해 별도 요구사항·PRD·용어 승인 기록이나 변경 이력 문서를 만들지 않는다.

## 작성 형식과 원본
기존 문서 형식을 존중하고, 신규 용어는 다음처럼 짧게 작성한다. 맥락은 상위 절에서 공유하고 예시·반례·근거 링크는 의미 구별에 필요할 때만 덧붙인다.

```markdown
## <업무 맥락>

**<대표 용어>**:
<중요한 경계를 포함한 짧은 정의>
_Avoid_: <이 맥락에서 혼동을 만드는 표현>
```

`Avoid`는 다른 맥락까지 금지하는 뜻이 아니다. 용어집에는 개념을 구별하는 핵심 의미를 담고 상세 정책·인수 조건·설계 결정은 요구사항·PRD·ADR을 참조한다. 같은 규칙의 복제본을 만들지 않는다.

## 미결정과 단계 간 인계
- 합의되지 않은 의미는 용어집에서 확정처럼 기록하지 않고 관련 요구사항·PRD가 있으면 그 가정·미결정에 남기고, 없으면 대화에서 질문과 영향을 보고한다. 용어 검토 자체는 남은 질문과 영향을 보고하고 마칠 수 있다. 기대 동작이 정해지지 않은 부분에 의존하는 작업만 보류하고, 독립적인 작업은 계속한다.
- [요구사항 탐색](../requirement-discovery/SKILL.md)은 합의와 용어집 갱신을 담당하고, [제품 명세](../specification/SKILL.md)는 PRD·인수 조건에서 같은 의미와 경계를 사용하는지 확인한다. 이후 단계에서도 이 절차로 의미 차이를 피드백한다.
- 제품 정책 변경은 요구사항·PRD에, 책임·협력·저장 구조 변경은 [engineering-planning](../engineering-planning/SKILL.md)에 반환한다. 용어집 갱신은 해당 변경의 승인이나 API·데이터 마이그레이션 실행 권한을 대신하지 않는다.

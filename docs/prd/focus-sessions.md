# 집중 세션 API

집중 세션은 사용자가 의도한 작업 기록이다. 관찰 활동과 별도로 저장하며, 관찰 시점에 진행 중인 세션을 activity_records.focus_session_id로 연결한다. 타임라인 구간에는 세션 외래키를 추가하지 않는다.

- POST /api/v1/focus-sessions: 클라이언트 UUID, 등록 deviceId, UTC startedAt, targetSeconds(0은 경과 시간)으로 세션을 먼저 생성한다. 동일 ID/내용 재시도는 안전하다.
- PUT /api/v1/focus-sessions/{session_id}/completion: 종료 시각, 일시중지 제외 작업 초, 활성 라벨, 선택 설명으로 완료한다. 완료는 확정이며 같은 요청 재시도만 허용한다.
- GET /api/v1/focus-sessions?date=YYYY-MM-DD: 계정 시간대의 시작 날짜 기준 완료 기록을 최신순 조회한다. 자정을 넘는 세션은 시작 날짜에 속한다.
- 활동의 focusSessionId는 선택적이다. 계정·기기 소유권과 세션 시간 범위를 검증한다. 일시중지 중 활동은 연결하지 않는다. 완료 후 늦게 도착한 유효한 관찰도 수용한다.

진행 중 세션은 완료 목록에서 제외한다. 앱 종료 후 타이머 재개 및 진행 중 세션 복구는 이 계약의 범위에 포함하지 않는다. 활동 업로드를 시작하기 전에 세션 생성 응답을 받아 외래키 선행 조건을 보장한다. 세션 시작과 완료의 네트워크 오류는 입력을 보존하고 동일 요청으로 재시도한다.

검증: 인증된 HTTP API와 PostgreSQL에서 생성/완료/조회, 재시도 충돌, 다른 계정 차단, 필수 라벨, 작업 시간 검증, 지연 활동 재전송 및 기존 클라이언트 호환을 확인한다.

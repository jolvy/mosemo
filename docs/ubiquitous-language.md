# Mosemo Domain

Mosemo가 계정에 귀속된 앱 설치와 그 설치에서 관찰한 활동을 일관된 용어로
설명하기 위한 도메인 언어다. 활동을 관찰한 사실과 그 사실에 대한 후속 해석을
구분한다.

## 계정과 Device

**Device**:
한 계정에 귀속되어 서버에 등록된 하나의 앱 설치다. 앱 재설치 등으로 등록 상태를
잃으면 이전 Device와 자동으로 연결하지 않고 새 Device로 취급하며, 서버 식별자는
`deviceId`다.
_Avoid_: Device Registration, physical device, hardware identity

**활성 기록 Device**:
한 계정에서 현재 활동을 기록할 수 있도록 로그인된 Device. 한 계정에는 최대 한
대만 존재한다.
_Avoid_: 최근 Device, 모든 Device

**계정 시간대**:
날짜 단위 관찰 타임라인에서 하루의 경계를 정하는 계정의 지원 IANA 시간대.
_Avoid_: 서버 시간대, 관찰 당시 시간대

## 활동 관찰

**활동 레코드**:
한 시점의 활동 관찰 또는 수집 가능 상태의 변화를 나타내는 원본 사실.
_Avoid_: 타임라인 항목, 활동 구간

**관찰 시각**:
Device가 활동 레코드에 기록한 시각. 서버에 처음 저장된 시각과 다를 수 있으며,
관찰 구간의 시간 경계와 여러 Device 원본의 시간순 병합에 사용한다. 동일 Device
내 관찰 순서는 sequence로 정한다.
_Avoid_: 서버 수신 시각, 저장 시각

**최초 저장 시각**:
활동 레코드가 서버에 처음 저장된 시각. 같은 레코드의 재전송 시각 및
Device가 기록한 관찰 시각과 구분한다.
_Avoid_: 관찰 시각, 재전송 시각

**관찰 타임라인**:
계정의 모든 Device에서 관찰된 활동과 관찰할 수 없었던 공백을 시간순으로 배치한
기록. Device 변경을 구간 경계로 삼거나 Device 출처를 노출하지 않으며, 사용자의
의도나 AI의 의미 해석을 포함하지 않는다.
_Avoid_: Event Log, 활동 흐름, AI 타임라인

**관찰 활동 구간**:
동일한 관찰 문맥이 60초를 초과해 끊기지 않고 이어진 반개구간 `[시작, 종료)`.
같은 시각에 다른 문맥이 관찰된 전환을 보존하기 위해 시작과 종료가 같은 구간도
유지하며, 원본 활동 문맥과 마지막 관찰 시각을 담는다.
_Avoid_: 활동 흐름, 원본 이벤트

**동일한 관찰 문맥**:
관찰 레코드의 식별자나 시각을 제외한 활동 문맥 전체가 같은 상태. 의미가 비슷한
활동을 뜻하지 않는다.
_Avoid_: 같은 활동 흐름, 유사한 활동

**동일 문맥 갱신**:
변화가 없는 활동 문맥이 계속 관찰되고 있음을 최대 30초 간격으로 알리는 관찰.
탭 또는 앱 전환을 발견하는 방식과는 다르다.
_Avoid_: 문맥 전환 감지, 새 활동

**관찰 문맥 전환**:
수집 공백이나 60초를 초과한 침묵 없이 한 관찰 문맥 뒤에 다른 문맥이 직접 관찰된
사실. 이전 구간과 새 구간은 새 문맥의 관찰 시각을 경계로 맞댄다.
_Avoid_: 컨텍스트 스위칭, 이탈

**열린 관찰 활동 구간**:
종료를 나타내는 후속 레코드가 없고 마지막 관찰 후 60초가 지나지 않은 최신 관찰
활동 구간. 마지막 관찰 시각 이후에도 활동이 계속된다는 보장은 아니다.
_Avoid_: 현재 활동, 무기한 활동

**수집 공백**:
수집 중단이나 관찰 실패로 실제 활동을 알 수 없는 시간 구간. 명시적인
`suspended`로 시작하고 수집 재개 후 첫 활동 관찰로 끝나며, 순번 누락이나 관찰
침묵만으로 추정하지 않는다.
_Avoid_: 비활동, 불투명 활동

**불투명 활동**:
활동은 관찰했지만 개인정보 보호를 위해 식별 정보를 남기지 않은 정상 활동.
라벨링 대상에서 제외한다.
_Avoid_: 수집 공백, 알 수 없는 오류

**타임라인 날짜**:
계정 시간대를 기준으로 관찰 타임라인 구간을 선택하는 달력 날짜. 날짜 경계와
겹치는 구간은 자르지 않으며, 길이가 없는 구간은 그 시각이 속한 날짜에만 속한다.
_Avoid_: 구간 절단 경계, UTC 날짜

**집중 세션**:
사용자가 한 작업에 집중하겠다고 시작하고, 끝낼 때 작업 시간·세션 라벨·설명을
남기는 작업 기록. Device가 관찰한 사실이 아니라 사용자가 직접 남긴 의도의 기록이며,
관찰 레코드가 진행 중인 세션을 가리킬 수 있다. 완료 후에는 같은 내용의 재시도만
허용하고, 자정을 넘는 세션은 계정 시간대의 시작 날짜에 속한다.
_Avoid_: 타이머, 포모도로, 관찰 활동 구간

**세션 라벨**:
사용자가 집중 세션을 완료할 때 그 세션이 어떤 작업이었는지 지정한 사용 중인 라벨.
관찰 활동 구간의 확정 라벨과 별개이며, 세션에 연결된 활동의 라벨을 정하거나 바꾸지
않는다.
_Avoid_: 확정 라벨, 라벨 제안

**세션 연결 활동**:
관찰 시점에 진행 중이던 집중 세션을 가리키는 활동 레코드. 관찰 시각은 세션의
시작~종료 안에 있어야 하고, 일시중지 구간의 관찰은 연결하지 않는다. 완료 후 늦게
도착한 유효한 관찰도 연결할 수 있다.
_Avoid_: 세션 구간, 집중 활동

**작업 시간**:
집중 세션의 시작~종료에서 일시중지한 시간을 뺀, 사용자가 완료 시 기록한 초 단위
시간. 경과 시간을 넘을 수 없고, 목표 시간이 있으면 목표 시간도 넘을 수 없다.
_Avoid_: 경과 시간, 분석 시간

**일시중지 구간**:
집중 세션 중 사용자가 타이머를 멈춘 반개구간 `[시작, 종료)`. 세션 완료 시 함께
기록하며, 세션의 시작~종료 안에 있고 서로 겹치지 않는다. 이 구간의 관찰은 세션에
연결하지 않는다. 일시중지 정보 없이 완료한 세션도 있다.
_Avoid_: 수집 공백, 집중 이탈

## 활동 해석

**라벨**:
사용자가 활동의 의미나 성격을 기준으로 붙이는 사용자별 대표 분류. 앱이나 관찰
행위가 달라도 같은 의미라면 같은 라벨을 붙일 수 있으며, 한 구간에는 기본 또는
사용자 정의 라벨을 최대 하나 지정한다.
_Avoid_: 카테고리, Task, 앱 종류, 다중 태그

**라벨 제안**:
AI가 관찰 사실과 해당 사용자의 확정 이력을 참고해 사용 중인 라벨 목록에서
골라 관찰 활동 구간에 제시한 라벨. 사용자가 확정하기 전의 판단이며, 이후
확정 이력이 쌓여도 이미 생성된 제안은 조용히 변경하지 않는다.
_Avoid_: 확정 라벨, 관찰 사실

**확정 라벨**:
사용자가 라벨 제안을 승인하거나 다른 라벨을 선택해 확정한 관찰 활동 구간의
라벨. 사용자가 나중에 정정할 수 있으며, 최신 확정값이 집계와 이후 제안에 반영된다.
_Avoid_: 라벨 제안, 자동 확정

**보관 라벨**:
새 활동의 라벨 제안과 선택에서는 제외하지만 과거 확정 활동에는 남아 있는 라벨.
_Avoid_: 삭제된 라벨, 미분류

**미분류**:
활동 성격을 판단할 근거가 부족해 라벨이 없는 관찰 활동 구간의 상태. AI가 이
상태로 남겨 두거나 사용자가 미분류로 확정할 수 있다.
_Avoid_: 불투명 활동, 수집 공백, 기본 라벨

**라벨 타임라인**:
라벨 대상인 관찰 활동 구간을 제안 또는 확정 라벨과 함께 시간순으로 보여주는
사용자용 보기이며 불투명 활동은 별도 항목으로 표시한다.
사이에 다른 라벨의 관찰이나 시간 공백이 없고 확정 상태도 같은 연속 구간만 묶는다.
_Avoid_: 관찰 타임라인, 라벨별 집계

**라벨별 활동 시간**:
선택한 기간에 사용자가 각 라벨로 확정한 활동 구간의 시간을 합산한 값. 확정된
미분류 시간은 별도로 표시하며, 미확정·불투명 활동과 관찰되지 않은 시간은
포함하지 않는다.
_Avoid_: 연속 활동 구간, 전체 경과 시간

**검토 대기 활동 시간**:
사용자가 아직 라벨이나 미분류를 확정하지 않은 라벨 대상 활동의 시간. 라벨별
활동 시간과 구분해 표시한다.
_Avoid_: 잠정 라벨별 활동 시간, 수집 공백

**불투명 활동 시간**:
선택한 기간의 불투명 활동 구간이 차지하는 시간. 라벨별 활동 시간과 검토 대기
활동 시간에서 분리해 표시한다.
_Avoid_: 미분류 시간, 수집 공백

## 활동 분석

**앱**:
상세 문맥 관찰 활동 구간에서 수집된 bundleId로 식별하는 분석 단위. bundleId를
수집하지 못한 구간과 불투명 활동은 어떤 앱에도 귀속하지 않는다.
_Avoid_: 라벨, 앱 종류, 사용 대상

**사이트**:
브라우저 탭 URL의 eTLD+1(예: `m.youtube.com` → `youtube.com`). `http`·`https` URL인데
eTLD+1을 정할 수 없으면(IP 주소, `localhost`) 호스트 그대로이고, 그 밖의 URL(`chrome://`,
`about:`)에는 사이트가 없다. 분석에서만 파생하며 원본 URL을 바꾸지 않는다. 브라우저가
달라도 같은 사이트다.
_Avoid_: 도메인, URL, 페이지

**사용 대상**:
사용 시간과 전환을 세는 단위. URL을 수집한 브라우저 구간은 사이트, URL이
비식별화·미수집인 브라우저 구간은 그 브라우저 앱, 브라우저가 아닌 구간은 그 앱이다.
앱 미확인 구간과 불투명 활동에는 사용 대상이 없다.
_Avoid_: 앱, 라벨, 활동

**사용 시간**:
선택한 기간에 한 앱 또는 사용 대상으로 관찰된 활동 구간의 시간 합계. 열린 구간은
마지막 관찰 시각까지만 포함하고 수집 공백과 관찰 침묵은 포함하지 않는다.
_Avoid_: 라벨별 활동 시간, 화면 켜짐 시간

**일간 통계**:
계정 시간대 하루의 사용 시간(C1)·사용 대상 전환(C2)·라벨 전환(C7) 결과. 지난 날짜는
저장해 두고 원천이 바뀌면 다시 계산하며, 오늘은 조회할 때 계산한다. 언제나 조회
시점의 원천을 반영한다.
_Avoid_: 마감 기록, 일일 스냅샷, 분석 칸

**사용 대상 전환**:
경계가 맞닿은 관찰 문맥 전환 중 양쪽 사용 대상이 식별되고 서로 다른 전환.
컨텍스트 스위칭이라고도 부른다. 같은 사용 대상 안의 창·탭·URL 변경, 다른
브라우저의 같은 사이트, 공백·침묵을 사이에 둔 변화는 포함하지 않는다.
_Avoid_: 관찰 문맥 전환, 앱 전환, 라벨 전환, 이탈

**라벨 전환**:
경계가 맞닿은 두 관찰 활동 구간이 모두 유효한 확정 라벨을 가지고 그 라벨이 다른
전환. 판정 대기·확정 미분류·불투명 활동·공백·침묵이 끼면 전환이 아니다.
_Avoid_: 사용 대상 전환, 이탈

**세션 분석 시간**:
완료된 집중 세션의 시작~종료에서 일시중지 구간을 뺀 시간. 일시중지 정보가 없으면
시작~종료 전체다. 사용자가 기록한 작업 시간과 다를 수 있다.
_Avoid_: 작업 시간, 경과 시간

**이탈 활동**:
세션 분석 시간 중 세션 라벨과 다른 라벨로 유효하게 확정된 활동. 확정 미분류,
미확정, 불투명 활동은 이탈 활동이 아니다.
_Avoid_: 미분류, 판정 대기, 사용 대상 전환

**판정 대기 시간**:
세션 분석 시간 중 유효한 확정이 없어 집중 또는 이탈을 판정할 수 없는 시간. 확정
후 구간이 재구성된 경우도 포함한다.
_Avoid_: 이탈 시간, 미분류

**집중 이탈**:
이탈 활동이 시작된 시점부터 세션 라벨의 확정 활동으로 돌아오거나 세션 분석 시간이
끝날 때까지 이어진 이탈 활동의 묶음.
_Avoid_: 사용 대상 전환, 일시중지

**방해 앱**:
집중 세션의 이탈 활동 중 사용한 사용 대상. 바로 앞 구간과 다른 사용 대상으로
들어갈 때마다 진입 1회를 센다. 집중 이탈을 시작한 사용 대상은 이탈 진입 대상으로
따로 부른다.
_Avoid_: 가장 많이 사용한 앱, 원인 추정

집중 이탈의 진입 문맥, 직전 집중 사용 대상, 경과 세션 분석 시간, 이탈 시간, 복귀

# 활동 분석 위험

[활동 분석 요구사항](requirements/activity-analytics.md)의 C1~C7과 일간 통계를 쓸 때 생기는 위험(지표 왜곡, 타당성,
개인정보, 정의 변경)과 측정 한계를 모은다. 각 위험의 대응과 결정 상태를 적고, 결정된 규칙은 요구사항에 둔다.

작성: 2026-11-13(6단계). 근거: [지표 명세](activity-analytics-metrics.md) 「측정」의 데이터 품질 Q1~Q8과 민감도 M1~M7,
저장소 코드(테이블 FK, 로깅). 측정 데이터는 계정 1개·6일이고 확정 라벨·집중 세션이 0건이라 C3~C7의 실제 분포는 아직
모른다. 실제 기록의 앱 이름·URL·창 제목·라벨 이름 원문은 이 문서에 쓰지 않는다.

표기: (측정)은 지표 명세에서 잰 값, (확인)은 저장소 코드에서 직접 본 사실, (가정)은 측정 전 가정이다. `UD-*`는
2026-11-13 사용자 결정, `P-*`는 요구사항 「분석 화면 원칙」이다.

## 지표 왜곡

사용자가 숫자를 움직이는 방법은 다음과 같다. 확정은 사용자의 권한이라 서버는 막지 않는다. 대응은 화면이 값을 함께
보여 주는 것(P-1, P-7)이다.

| ID | 사용자가 하는 일 | 지표에서 생기는 일 |
| --- | --- | --- |
| K1 확정 미루기 | 구간을 확정하지 않고 둔다 | 판정 대기로 남아 이탈·라벨 전환에서 빠진다(FR-14, FR-23) |
| K2 미분류 확정 | 구간을 "미분류"로 확정한다 | 확정 미분류는 이탈이 아니다(2026-10-25 결정) |
| K4 관찰 피하기 | 수집을 멈추거나, 불투명 대상에 넣거나, URL이 수집되지 않는 브라우저로 옮긴다 | 수집 공백·불투명·브라우저 앱으로 잡혀 사이트·전환·이탈에서 빠진다 |
| K5 세션 경계 바꾸기 | 일시중지하거나, 세션을 쪼개거나, 세션 라벨을 넓게 잡는다 | 일시중지 시간은 C3~C6에서 빠진다(FR-13). 넓은 세션 라벨은 이탈을 줄인다 |

어떤 활동을 어떤 라벨로 확정할지는 사용자가 정하고 그 확정이 정답이다(UD-7). 서버는 확정 라벨의 진위를 확인하거나
드러내지 않으며, 이를 가리는 지표를 만들지 않는다.

## 한계

- 「지표 왜곡」의 행동은 사용자 연구가 아니라 정의에서 끌어낸 가능성이다. 실제로 일어나는지는 기록일과 실사용 데이터로
  확인한다.
- C3~C7 실제 데이터가 없어(R-V9) 왜곡의 크기를 재지 못했다. M5만 합성 확정으로 잰 값이다.
- 계정 삭제 시 RESTRICT 동작(R-P2b), S3 Glacier Instant Retrieval의 최소 보관 기간 요금, S3 버전 관리의 삭제 동작은
  문서·지식 기반이며 재현하지 않았다.

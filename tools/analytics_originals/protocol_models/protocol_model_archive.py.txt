"""6단계 후속 F-3: 90일 지난 날짜의 아카이브·S3 재계산·늦은 관찰 거부·계정 삭제 상태 모델(표준 라이브러리만).

기존 파일(protocol_model*.py)은 고치지 않는다. 추천 프로토콜(V5 + 재시도·격리 + 시간대 결정 (a))을 옮겨 적고,
사용자 결정(2026-11-13, PLAN.md 끝 줄 UD-1·UD-2·UD-3)의 아카이브 경로를 더한다.

날짜의 원천 상태(ast): 'db'(DB 원천) → 'arch'(아카이브 중, DB 원천 그대로) → 's3'(S3 원천).

원천 모델: 부분(part)은 같은 시각 범위의 구간·라벨 확정이다(값 = 변경 횟수). 시각 순서 p < l < c < q < r.
  p  d1의 구간                         l  d1의 라벨 확정(원본 레코드 삭제 시 CASCADE로 함께 지워짐)
  c  d1에서 시작해 d2로 이어지는 구간  q  d2의 구간            r  d3의 구간
  T1에서 날짜별 읽기 집합(D1 경계 읽기 + D2 거슬러 읽기): d1 = {p,l,c}, d2 = {c,q}, d3 = {r}.
  c는 d2 계산에도 읽힌다(자정을 넘는 체류이거나 D2로 거슬러 읽는 앞 구간). home(c) = d1(시작 날짜).
  시간대 T2는 시나리오가 정한다: 'behind'(예 서울→뉴욕, 시각의 날짜가 같거나 하루 앞) / 'ahead'(반대).

아카이브(6단계 초안 R-P2 순서, 날짜 d1 → d2 차례로, 날짜가 90일을 지난 뒤에만):
  A.start   계정 advisory 잠금 안에서: 계정이 살아 있고, 날짜가 동결되었고, 그 날짜에 표시가 없고, 저장 행이 있으면
            ast = 'arch' 커밋. 아니면 그 실행의 아카이브를 멈춘다(다음 날 다시, 모델 밖).
  A.copy    ① DB에서 대상 날짜의 구간·확정을 S3 파일 (계정, 날짜)에 쓴다(파일에 쓴 때의 tz 기록). 잠금 없음.
  A.verify  ② 파일 내용 = 지금 DB 내용인지 확인. 다르면 ①로.
  A.delseg  ③ 한 트랜잭션: 확정·구간 삭제 + ast = 's3'.
  A.delrec  ④ 원본 레코드 삭제(그 날짜를 시작으로 하는 구간이 DB에 남아 있으면 FK 때문에 남김). ⑤ 세션 삭제는 일간
            통계와 무관해 넣지 않았다.
원천 변경(늦은 관찰 포함): 잠금 → 계정 tz 읽기 → 동결 확인(그 부분을 읽는 날짜 중 동결된 날짜가 있으면 거부) → 커밋
  (DB 값 +1, 읽는 날짜마다 표시). 동결은 시간이 지나며 d1, d2 차례로 일어나는 사건(라벨 기준, 현재 tz의 날짜).
배치(V5 + 재시도·격리): 선점(attempts < K, attempts+1, version·ast 기억) → 읽기(ast가 db·arch면 DB 부분을 하나씩,
  s3면 S3 파일을 읽기 규칙대로 한 번에) → 저장 트랜잭션(정의·tz·계정 살아 있음·ast가 선점 때와 같은 경로인지 확인,
  sv guard, 같은 version일 때만 표시 삭제) 또는 실패(표시 남음).
조회(REPEATABLE READ 한 스냅샷 = 한 단계): 계정이 삭제됨이면 거부. ast = s3면 계산하지 않는다: 표시가 있거나
  저장 행의 정의·tz가 현재와 다르면 저장 값 + "이전 기준", 아니면 저장 값. ast = db·arch면 4B·F-2 그대로.
정의 변경: 정의 행 올림 → 잠금 → 옛 정의 저장 날짜(S3 날짜 포함)에 표시.
시간대 변경: 잠금 → tz UPDATE → (저장 ∪ 표시) ±1일에 표시 → 커밋.
계정 삭제(UD-1): 삭제 요청(잠금 안에서 acct = 'deleted') → 새벽 배치: DB 삭제(한 트랜잭션) → S3 삭제 → 'purged'.

불변식(기존 I1~I9를 아카이브 날짜에 맞게 정밀화, I10~I14 새로):
  I1  조회 결과: ast가 db·arch인 날짜는 "현재 정의·현재 tz·논리 원천"의 계산값. ast가 s3인 날짜는 같은 값이거나,
      "이전 기준" 표시가 붙은 저장 값이고 그 저장 값 = (저장 행의 정의·tz, 지금의 논리 원천)의 계산값이다. 즉 기준만
      바뀐 옛 값은 허용, 원천이 바뀐 옛 값은 금지. 논리 원천 = 받아들인 원천 변경을 모두 반영한 값(유령 변수).
      조회는 한 단계이므로 모든 상태·모든 날짜에서 검사한다(J).
  I2  끝 상태에서 격리를 해제하고 배치를 혼자 최대 2번 더 돌리면 표시 0, 저장 행 = 현재 정의·tz·논리 원천 계산값
      (S3 날짜도 S3 재계산으로). 계정이 지워졌으면 생략.
  I3  저장 값의 정의 = 그 행의 정의(배치가 코드 정의로 계산) — 구조로 성립, I5와 함께 검사.
  I4  원천 커밋은 배치·아카이브가 계산·복사 동안 쥔 잠금을 기다리지 않는다 — 구조로 성립(아카이브가 잠금을 쥐는 것은
      A.start 한 단계뿐이고 S3 쓰기 동안은 쥐지 않음).
  I5  저장 행의 정의 version은 줄지 않는다.      I9  저장 행의 tz는 새 tz가 된 뒤 옛 tz로 돌아가지 않는다.
  I6  격리된 표시(attempts >= K)는 저장 없이 사라지지 않는다(삭제 배치 제외).  I7  attempts <= 현재 version 선점 수.
  I8  I2 상태에서 현재 tz로 활동이 있는 날짜는 저장 행이 있다.
  I10 아카이브 중 원천 유실 없음: 모든 상태에서 각 부분의 논리 값이 DB에 있거나(같은 값), DB에 없으면 어느 S3
      파일에 같은 값으로 있다. 라벨 확정(l)의 유실은 I11로 따로 센다.
  I12 동결: arch·s3 날짜가 (현재 tz로) 읽는 부분을 바꾸는 원천 커밋이 없다.
  I13 계정 삭제 배치가 끝난 뒤(purged) DB(원천·레코드·표시·저장 행)와 S3가 모두 비어 있다(모든 상태).
  I14 삭제된 계정은 조회되지 않는다: 계정 삭제 요청 커밋 뒤의 스냅샷으로 데이터를 돌려주는 조회가 없다.

실행:
  python3 protocol_model_archive.py                # 모든 변형·시나리오
  python3 protocol_model_archive.py R0 X1 --trace  # 일부 변형, 가장 짧은 반례 출력
"""

from __future__ import annotations

import sys
import time
from collections import deque
from dataclasses import dataclass, replace

K = 2
DATES = ("d1", "d2", "d3")
ND = 3
PARTS = ("p", "l", "c", "q", "r")
PI = {x: i for i, x in enumerate(PARTS)}
CONF = {"l"}
T1, T2 = 1, 2
ARCH_DATES = (0, 1)

# 날짜별 읽기 집합과 시작 날짜(home). T2는 시나리오의 shift가 정한다.
LAYOUT = {
    "none": {T1: ((("p", "l", "c"), ("c", "q"), ("r",)), {"p": 0, "l": 0, "c": 0, "q": 1, "r": 2})},
    # 서울→뉴욕처럼 시각의 날짜가 같거나 하루 앞(더 이른 날짜)으로: q가 d1로, r이 d2로
    "behind": {T1: ((("p", "l", "c"), ("c", "q"), ("r",)), {"p": 0, "l": 0, "c": 0, "q": 1, "r": 2}),
               T2: ((("p", "l", "c", "q"), ("r",), ()), {"p": 0, "l": 0, "c": 0, "q": 0, "r": 1})},
    # 뉴욕→서울처럼 하루 뒤로: c가 d2로(d1은 p,l만), q는 d2 그대로 d3까지 이어짐
    "ahead": {T1: ((("p", "l", "c"), ("c", "q"), ("r",)), {"p": 0, "l": 0, "c": 0, "q": 1, "r": 2}),
              T2: ((("p", "l"), ("c", "q"), ("q", "r")), {"p": 0, "l": 0, "c": 1, "q": 1, "r": 2})},
}


def R(shift, tz, di):
    return LAYOUT[shift][tz][0][di]


def home(shift, tz, x):
    return LAYOUT[shift][tz][1][x]


def readers(shift, tz, x):
    return [d for d in range(ND) if x in R(shift, tz, d)]


def f(dfn, tz, di, vals, shift):
    """일간 통계 계산: (정의, tz, 날짜, 읽기 집합의 (부분, 값)). 읽지 못한 부분은 값 None."""
    return (dfn, tz, DATES[di], tuple((x, vals[PI[x]]) for x in R(shift, tz, di)))

@dataclass(frozen=True)
class Variant:
    name: str
    note: str
    fc: str = "home"        # S3 파일 내용: home(그 날짜에 시작한 구간·확정) | read(그 날짜의 읽기 집합 전부)
    dr: str = "home"        # DB 삭제 대상: home(그 날짜에 시작한 것) | need(현재 tz로 DB 날짜가 더는 읽지 않는 것)
                            # | needall(지원하는 어느 tz로도 DB 날짜가 읽지 않는 것 = 실제로는 하루 여유)
    rr: str = "dprev"       # S3 재계산 읽기: d(그 날짜 파일만) | dprev(그 날짜+전날 파일) | nbr(전날·그 날짜·다음 날 파일)
                            # | union(nbr 파일 ∪ DB에 남은 행)
    late: str = "reject"    # 동결 날짜를 읽는 부분의 원천 변경: reject | allow
    freeze: str = "label"   # label: 동결 = 현재 tz 날짜가 90일 지남(날짜 라벨) | mono: 한 번 동결된 시각은 tz가 바뀌어도
                            # 동결 그대로(계정별 동결 시각 하한, 줄지 않음)
    order: str = "design"   # design | conf_last(구간만 복사·삭제 → 원본 삭제 → 확정 복사) | flip_late(ast=s3를 삭제 뒤
                            # 별도 커밋) | s3_first(시작에서 바로 ast=s3)
    verify: bool = True     # ② 확인(False면 ②도, ③에서 "그 값이 S3 파일에 있는 행만 지움" 대조도 없음)
    startlock: bool = True  # A.start가 계정 잠금을 잡는가(늦은 관찰 경합 차단)
    mkblock: bool = True    # 표시 있는 날짜는 아카이브하지 않음
    astcheck: bool = True   # 배치 저장 때 ast 경로 확인
    qold: bool = True       # s3 날짜 조회가 표시 있으면 옛 값+이전 기준(사용자 결정). False면 원천 계산 시도(S3 읽기 없음 = DB)
    delexcl: bool = True    # 삭제 배치와 아카이브 날짜 처리가 겹치지 않음(같은 job 차례 실행 또는 계정 아카이브 잠금)
    bdelcheck: bool = True  # 배치 저장 트랜잭션이 계정 삭제 여부 확인
    sdelcheck: bool = True  # 원천 쓰기가 계정 삭제 여부 확인
    qdelcheck: bool = True  # 조회 스냅샷이 계정 삭제 여부 확인


@dataclass(frozen=True)
class Scenario:
    name: str
    changes: tuple = ()     # 원천 변경이 바꾸는 부분 순서
    def_change: bool = False
    shift: str = "none"     # 시간대 변경 있음이면 behind | ahead
    delete: bool = False
    marker: int = -1        # 시작 때 이 날짜에 원천 표시(저장 대기) 하나
    fails: int = 0          # 배치 계산 실패 예산
    cfaults: int = 0        # 부분 복사(확정 누락) 예산
    batches: int = 2

    def label(self):
        bits = [self.name, "변경 " + ("→".join(self.changes) or "없음")]
        if self.def_change:
            bits.append("정의변경")
        if self.shift != "none":
            bits.append("tz " + self.shift)
        if self.delete:
            bits.append("계정삭제")
        if self.marker >= 0:
            bits.append(f"초기표시 {DATES[self.marker]}")
        if self.fails:
            bits.append(f"실패{self.fails}")
        if self.cfaults:
            bits.append(f"부분복사{self.cfaults}")
        return "·".join(bits)

TRUTH, SRC, REC, S3, AST, FRZ, SEQ, TZ, MK, ST, DEF, ADV, ACCT, FB, CB, QDEL, FZP = range(17)

# 프로세스
P_CLK, P_ARC, P_SRC, P_TZ, P_DEF, P_B1, P_B2, P_DEL, P_Q = range(NG, NG + 9)


def initial(v: Variant, sc: Scenario):
    vals = (0,) * len(PARTS)
    st = [None] * ND
    mk = [None] * ND
    for d in range(ND):
        if R(sc.shift, T1, d):
            st[d] = (1, T1, 1, f(1, T1, d, vals, sc.shift))
    seq = 2
    if sc.marker >= 0:
        mk[sc.marker] = (seq, 0, 0)
        seq += 1
    g = (vals, vals, (True,) * ND, (None,) * ND, ("db",) * ND, 0, seq, T1, tuple(mk), tuple(st), 1, None,
         "live", sc.fails, sc.cfaults, False, frozenset())
    clk = ("run",)
    arc = ("start", 0)
    srcp = ("draw", 0, None, None) if sc.changes else ("done", 0, None, None)
    tzp = ("start",) if sc.shift != "none" else ("done",)
    defp = ("bump",) if sc.def_change else ("done",)
    batch = ("start", None, None, None, None, None, ())
    b2 = batch if sc.batches >= 2 else ("done", None, None, None, None, None, ())
    delp = ("flag",) if sc.delete else ("done",)
    q = ("idle", None) if sc.delete else ("done", None)
    return g + (clk, arc, srcp, tzp, defp, batch, b2, delp, q)


def setp(tup, i, val):
    lst = list(tup)
    lst[i] = val
    return tuple(lst)


def s3_lookup(v, g, di, shift):
    """S3 재계산이 읽는 값: 읽기 규칙의 파일들(+union이면 DB). 가까운 파일이 먼저."""
    order = {"d": [di], "dprev": [di, di - 1], "nbr": [di, di - 1, di + 1], "union": [di, di - 1, di + 1]}[v.rr]
    vals = [None] * len(PARTS)
    if v.rr == "union":
        for i, x in enumerate(g[SRC]):
            if x is not None:
                vals[i] = x
    for d in order:
        if 0 <= d < ND and g[S3][d] is not None:
            for x, val in g[S3][d][1]:
                if vals[PI[x]] is None:
                    vals[PI[x]] = val
    return tuple(vals)


def query(v, g, di, shift):
    """조회 한 스냅샷. (결과, 이전 기준 표시) 또는 ('denied', False)."""
    if v.qdelcheck and g[ACCT] != "live":
        return "denied", False
    mk, row, cur, tz = g[MK][di], g[ST][di], g[DEF], g[TZ]
    if g[AST][di] == "s3" and v.qold:
        if row is None:
            return None, False
        old = mk is not None or row[0] != cur or row[1] != tz
        return row[3], old
    if mk is None and row is not None and row[0] == cur and row[1] == tz:
        return row[3], False
    return f(cur, tz, di, g[SRC], shift), False


def query_ok(g, di, shift, res, old):
    if res == "denied":
        return True
    truth = g[TRUTH]
    if not old:
        return res == f(g[DEF], g[TZ], di, truth, shift)
    row = g[ST][di]
    return res is not None and res == f(row[0], row[1], di, truth, shift)


def frozen_dates(g):
    return set(range(g[FRZ]))


def copy_parts(v, g, di, shift, conf=True, seg=True):
    tz = g[TZ]
    if v.fc == "home":
        xs = [x for x in PARTS if home(shift, tz, x) == di]
    else:
        xs = list(R(shift, tz, di))
    return [x for x in xs if (x in CONF and conf) or (x not in CONF and seg)]


def delete_parts(v, g, di, shift, ast_after):
    """③에서 DB에서 지울 부분. ast_after: 이 날짜를 s3로 본 날짜별 상태."""
    tz = g[TZ]
    if v.dr == "home":
        return [x for x in PARTS if home(shift, tz, x) == di]
    # need: 현재 tz로 그 행을 읽는 날짜가 모두 S3 원천이고, 그 행이 어느 S3 파일에 같은 값으로 있을 때만 지운다.
    out = []
    for x in PARTS:
        val = g[SRC][PI[x]]
        if val is None:
            continue
        tzs = (tz,) if v.dr == "need" else tuple(LAYOUT[shift])
        if all(ast_after[d] == "s3" for t in tzs for d in readers(shift, t, x)) and \
                (not v.verify or any(fl is not None and (x, val) in fl[1] for fl in g[S3])):
            out.append(x)
    return out


def successors(v: Variant, sc: Scenario, s):
    shift = sc.shift
    out = []
    procs = list(s[NG:])

    def emit(label, g, newprocs, viol=()):
        g = tuple(g)
        viol = list(viol)
        for d in range(ND):
            a, b = s[ST][d], g[ST][d]
            if a is not None and b is not None:
                if b[0] < a[0]:
                    viol.append("I5")
                if a[1] == g[TZ] and b[1] != g[TZ]:
                    viol.append("I9")
            ma, mb = s[MK][d], g[MK][d]
            if ma is not None and mb is None and g[ACCT] == "live":
                if b is None or b[2] < ma[0]:
                    viol.append("I6" if ma[1] >= K else "I6g")
        out.append((label, g + tuple(newprocs), viol))

    def G():
        return list(s[:NG])

    def P(i, val):
        p = list(procs)
        p[i - NG] = val
        return p

    adv_free = s[ADV] is None

    # 시간(동결): d1, d2 차례로 90일을 지난다
    if s[P_CLK][0] == "run":
        if s[FRZ] < 2:
            g = G()
            g[FRZ] += 1

                 P(P_CLK, ("run",) if g[FRZ] < 2 else ("done",)))

                else:
                    g = G()
                    g[AST] = setp(g[AST], d, "s3" if v.order == "s3_first" else "arch")
                    emit(f"아카이브 {DATES[d]} 시작: ast={g[AST][d]}", g, P(P_ARC, ("copy", adi)))
        else:
            d = ARCH_DATES[adi]
            if apc == "copy":
                conf_now = v.order != "conf_last"
                xs = copy_parts(v, s, d, shift, conf=conf_now)
                content = tuple(sorted((x, s[SRC][PI[x]]) for x in xs if s[SRC][PI[x]] is not None))
                nxt = "verify" if v.verify else "delseg"
                g = G()
                g[S3] = setp(g[S3], d, (s[TZ], content))

                    emit(f"아카이브 {DATES[d]} ① S3 복사 중 장애: 확정 빠진 파일 {part}", g, P(P_ARC, (nxt, adi)))
            elif apc == "verify":

                else:

            elif apc == "delseg":

                emit(f"아카이브 {DATES[d]} ③ 구간·확정 삭제 {xs}" + (", ast=s3" if v.order in ("design", "conf_last") else ""),

            elif apc == "delrec":

                segs_left = [x for x in PARTS if x not in CONF and home(shift, tz, x) == d and g[SRC][PI[x]] is not None]

                     g, P(P_ARC, (nxt, adi)))
            elif apc == "copyconf":

                xs = copy_parts(v, s, d, shift, conf=True, seg=False)

            elif apc == "flip":

    pc, k, drawn, htz = s[P_SRC]
    if pc == "draw" and adv_free:

                 G(), P(P_SRC, nxt))
        else:
            g = G()
            val = g[SEQ]
            g[SEQ] += 1
            g[ADV] = "S"
            emit(f"원천{k + 1}({x}) 시작: 잠금, nextval={val}, tz=T{s[TZ]}", g, P(P_SRC, ("commit", k, val, s[TZ])))
    elif pc == "commit":
        x = sc.changes[k]
        g = G()
        i = PI[x]
        truth = list(g[TRUTH])
        truth[i] += 1
        g[TRUTH] = tuple(truth)
        g[SRC] = setp(g[SRC], i, truth[i])
        mk = list(g[MK])
        rd = readers(shift, htz, x)
        for d in rd:
            mk[d] = (drawn, 0, 0)
        g[MK] = tuple(mk)
        g[ADV] = None
        viol = []
        if any(s[AST][d] in ("arch", "s3") for d in readers(shift, s[TZ], x)):

        if s[ACCT] == "purged":
            pass  # I13은 상태 검사가 잡는다
        nxt = ("draw", k + 1, None, None) if k + 1 < len(sc.changes) else ("done", k + 1, None, None)
        emit(f"원천{k + 1}({x}) 커밋: {x}={truth[i]}, 표시 {[DATES[d] for d in rd]}={drawn}", g, P(P_SRC, nxt), viol)

    elif s[P_TZ][0] == "commit":

def check_state(v, sc, s):
    viol = []
    if s[ACCT] == "purged":
        if any(x is not None for x in s[SRC]) or any(s[REC]) or any(m is not None for m in s[MK]) \
                or any(r is not None for r in s[ST]) or any(f_ is not None for f_ in s[S3]):
            viol.append("I13")
        return viol
    if s[ACCT] != "live":
        return viol
    for d in range(ND):
        res, old = query(v, s, d, sc.shift)
        if not query_ok(s, d, sc.shift, res, old):
            viol.append("I1")
            break
    for i, x in enumerate(PARTS):
        t = s[TRUTH][i]
        if s[SRC][i] == t:
            continue
        if s[SRC][i] is None and any(fl is not None and (x, t) in fl[1] for fl in s[S3]):
            continue
        viol.append("I11" if x in CONF else "I10")
    for d in range(ND):
        m = s[MK][d]
        if m is not None and m[1] > m[2]:
            viol.append("I7")
    return viol


def is_terminal(s):
    return all(p[0] == "done" for p in s[NG:])


def solo_batch(v, g, shift):
    g = list(g)
    worked = False
    for d in range(ND):
        m = g[MK][d]
        if m is None:
            continue
        worked = True
        if g[AST][d] == "s3":
            vals = s3_lookup(v, g, d, shift)
        else:
            vals = g[SRC]
        val = f(g[DEF], g[TZ], d, vals, shift)
        row = g[ST][d]
        if row is None or m[0] > row[2]:
            g[ST] = setp(g[ST], d, (g[DEF], g[TZ], m[0], val))
        g[MK] = setp(g[MK], d, None)
    return tuple(g), worked


def rows_ok(g, shift):
    if any(m is not None for m in g[MK]):
        return False
    for d in range(ND):
        row = g[ST][d]
        if row is not None and row != (g[DEF], g[TZ], row[2], f(g[DEF], g[TZ], d, g[TRUTH], shift)):
            return False
    return True


def check_terminal(v, sc, s):
    g = s[:NG]
    if g[ACCT] != "live":
        return [], 0
    # 격리 해제(runbook SQL): attempts = 0
    g = setp(g, MK, tuple(None if m is None else (m[0], 0, m[2]) for m in g[MK]))
    for runs in range(3):
        if rows_ok(g, sc.shift):
            viol = [f"I8" for d in range(ND) if R(sc.shift, g[TZ], d) and g[ST][d] is None]
            return viol[:1], runs
        if runs == 2:
            break
        g, worked = solo_batch(v, g, sc.shift)
        if not worked:
            break
    return ["I2"], None

@dataclass
class Result:
    states: int = 0
    transitions: int = 0
    terminals: int = 0
    orders: int = 0
    max_depth: int = 0
    solo_runs_max: int = 0
    s3_terminals: int = 0
    old_answers: int = 0
    s3_saves: int = 0
    violations: dict = None
    first: dict = None
    parents: dict = None
    seconds: float = 0.0


def explore(v, sc, keep_parents=False):
    t0 = time.time()
    init = initial(v, sc)
    seen = {init: None}
    depth = {init: 0}
    frontier = deque([init])
    res = Result(violations={}, first={})

    def hit(kind, state, via=None, prev=None):
        res.violations[kind] = res.violations.get(kind, 0) + 1
        if kind not in res.first:
            res.first[kind] = (state, via, prev)

    for kind in check_state(v, sc, init):
        hit(kind, init)
    succ_cache = {}
    while frontier:
        s = frontier.popleft()
        succ = successors(v, sc, s)
        succ_cache[s] = None
        if not succ:
            if is_terminal(s):
                res.terminals += 1
                if any(a == "s3" for a in s[AST]):
                    res.s3_terminals += 1
                viol, runs = check_terminal(v, sc, s)
                for kind in viol:
                    hit(kind, s)
                if runs is not None:
                    res.solo_runs_max = max(res.solo_runs_max, runs)
            else:
                hit("DEADLOCK", s)
            continue
        for label, ns, viol in succ:
            res.transitions += 1
            if "저장+표시 삭제" in label and s[P_B1 if label.startswith("배치1") else P_B2][5] == "s3":
                res.s3_saves += 1
            for kind in viol:
                hit(kind, ns, label, s)
            if ns not in seen:
                seen[ns] = (s, label) if keep_parents else None
                depth[ns] = depth[s] + 1
                res.max_depth = max(res.max_depth, depth[ns])
                for kind in check_state(v, sc, ns):
                    hit(kind, ns)
                if ns[ACCT] == "live" and any(query(v, ns, d, sc.shift)[1] for d in range(ND)):
                    res.old_answers += 1
                frontier.append(ns)
    res.states = len(seen)
    res.parents = seen if keep_parents else None
    del depth, succ_cache

    memo = {}
    onstack = set()
    stack = [(init, None)]
    while stack:
        st, succ = stack.pop()
        if st in memo:
            continue
        if succ is None:
            succ = [ns for _, ns, _ in successors(v, sc, st)]
            onstack.add(st)
            stack.append((st, succ))
            for ns in succ:
                if ns in onstack:
                    raise RuntimeError("상태 그래프에 순환이 있다")
                if ns not in memo:
                    stack.append((ns, None))
        else:
            memo[st] = 1 if not succ else sum(memo[ns] for ns in succ)
            onstack.discard(st)
    res.orders = memo[init]
    res.seconds = time.time() - t0
    return res


def trace(res, state):
    path = []
    while res.parents[state] is not None:
        prev, label = res.parents[state]
        path.append((label, state))
        state = prev
    path.reverse()
    return path

    replace(R3, name="X6", note="대조: 아카이브 시작이 계정 잠금을 잡지 않음", startlock=False),
    replace(R3, name="X7", note="대조: 표시 남은 날짜도 아카이브", mkblock=False),

SCENARIOS = [
    Scenario("S1", ("q", "c")),
    Scenario("S2", ("c", "q"), fails=1),
    Scenario("S3", ("l", "r"), cfaults=1),
    Scenario("S4", ("q",), def_change=True),
    Scenario("S5", ("q",), marker=0),
    Scenario("S6", ("q",), shift="behind"),
    Scenario("S7", ("c",), shift="ahead"),
    Scenario("S8", ("q",), delete=True, batches=1),
    Scenario("S9", ("l",), def_change=True, cfaults=1, batches=1),
    Scenario("S10", (), def_change=True, shift="behind"),
    Scenario("S11", ("c",), def_change=True, shift="ahead"),
    Scenario("S12", ("q", "r"), shift="behind"),
    Scenario("S13", ("r", "c"), shift="ahead", fails=1),
    Scenario("S14", ("q",), def_change=True, delete=True),
    Scenario("S15", (), def_change=True, fails=1, marker=1),
    Scenario("S16", ("c",), shift="ahead", delete=True, batches=1),
]


def run(names, show_trace, scen_names):
    chosen = [v for v in VARIANTS if not names or v.name in names]
    scens = [sc for sc in SCENARIOS if not scen_names or sc.name in scen_names]
    total_states = total_orders = 0
    summary = []
    t_all = time.time()
    for v in chosen:
        agg = {}
        rows = []
        for sc in scens:
            r = explore(v, sc, keep_parents=show_trace)
            total_states += r.states
            total_orders += r.orders
            rows.append((sc, r))
            for k_, n in r.violations.items():
                agg[k_] = agg.get(k_, 0) + n
        verdict = "통과" if not agg else "실패 " + ",".join(sorted(agg))
        summary.append((v, verdict, sum(r.states for _, r in rows), sum(r.orders for _, r in rows)))
        print(f"\n=== {v.name}: {v.note}", flush=True)
        for sc, r in rows:
            vio = ", ".join(f"{k_}:{n}" for k_, n in sorted(r.violations.items())) or "없음"
            print(f"  {sc.label():40s} 상태 {r.states:>9,} 끝 {r.terminals:>6,}(S3 {r.s3_terminals:>6,}) "
                  f"순서 {r.orders:>20,} 깊이 {r.max_depth:>2} 추가배치≤{r.solo_runs_max} 이전기준상태 {r.old_answers:>7,} "
                  f"S3저장 {r.s3_saves:>6,} {r.seconds:6.1f}s 위반 {vio}", flush=True)
        print(f"  판정: {verdict}")
        if show_trace and agg:
            best = {}
            for sc, r in rows:
                for kind, (st, via, prev) in r.first.items():
                    path = trace(r, prev) + [(via, st)] if prev is not None else trace(r, st)
                    if kind not in best or len(path) < len(best[kind][1]):
                        best[kind] = (sc, path, st, via)
            for kind, (sc, path, st, via) in sorted(best.items()):
                print(f"  -- {kind} 가장 짧은 반례 ({sc.label()}, {len(path)}단계)")
                print(f"     0. 초기: {show_state(initial(v, sc))}")
                for i, (label, s2) in enumerate(path, 1):
                    print(f"     {i}. {label}\n        → {show_state(s2)}")
                if kind in ("I1",) and via is None:
                    for d in range(ND):
                        res_, old = query(v, st, d, sc.shift)
                        print(f"     조회 {DATES[d]}: {res_}{' (이전 기준)' if old else ''} / 정답 "
                              f"{f(st[DEF], st[TZ], d, st[TRUTH], sc.shift)}")
                if kind in ("I2", "I8"):
                    g = setp(st[:NG], MK, tuple(None if m is None else (m[0], 0, m[2]) for m in st[MK]))
                    for n in range(2):
                        g2, worked = solo_batch(v, g, sc.shift)
                        print(f"     +{n + 1}. 추가 배치(혼자): {'일 없음' if not worked else '처리'} → "
                              f"{show_state(g2 + (None,) * 9)}")
                        g = g2
                    print("     정답: " + "; ".join(f"{DATES[d]}={f(st[DEF], st[TZ], d, st[TRUTH], sc.shift)}"
                                               for d in range(ND)))
    print("\n=== 요약")
    for v, verdict, ns, no in summary:
        print(f"  {v.name:4s} {verdict:28s} 상태 {ns:>11,} 실행순서 {no:>24,}  {v.note}")
    print(f"\n합계: 상태 {total_states:,}, 실행 순서 {total_orders:,}, {time.time() - t_all:.1f}s")


if __name__ == "__main__":
    args = [a for a in sys.argv[1:] if not a.startswith("--")]
    vnames = [a for a in args if not a.startswith("S")]
    snames = [a for a in args if a.startswith("S")]
    run(vnames, "--trace" in sys.argv, snames)
